# 常见问题

### 为什么已经有无感认证，还需要这个？

无感认证可用时程序会直接结束。它的作用是提供定时连接和未认证时的正常密码登录备用流程，而不是替代学校的无感功能。并非每个用户都需要这个工具。

### 可以直接打开保存的网址吗？

有些学校需要本次网关带来的终端参数。程序先连接校园 Wi-Fi，再通过 HTTP 跳转发现新入口；浏览器还可执行网关生成的跳转，最后才使用学校配置的备用入口。不会把昨天带会话参数的链接当永久地址。

### 输入框是看屏幕坐标点的吗？

不是。湘大浏览器规则使用 DOM 选择器找账号、密码、协议、按钮和 iframe；HTTP 学校原型读取当前表单或服务器配置。页面改版仍可能需要更新规则，不能自动适配任意登录页。

### 为什么外网有网时还切校园网？

设置的校园 Wi-Fi 可见时，它在计划执行那一轮优先于热点。目标不存在则保留当前网络并结束；没有持续抢网。

### 在家会一直尝试吗？

不会。只在设置的时刻执行；目标 Wi-Fi 不在附近时退出。默认没有登录后补跑或每两分钟检查。

### 07:01 没连上，会再等到学校开网吗？

不会无限重试。学校限制认证时间时该次结束。应把计划设在学校允许时段，或自行添加另一个合理时间；程序不能让学校提前开网。

### 手机远控离线就代表校园网没认证成功吗？

不一定。远控软件自身可能没启动、没连回服务器或需要登录。请结合本机运行记录和实际网页访问判断；“提交登录成功”也不等于外网一定可用，程序会另做外网检查。

### 重启、锁屏和睡眠有什么影响？

锁屏可以执行，开机但未登录、关机和注销不能执行。休眠唤醒受系统限制；任务的唤醒设置不保证硬件一定配合。可选的登录后补连只补两小时以内尚未执行的最近时段，不支持自动开机或登录。

### 为什么密码保存后看不到了？

密码框清空表示不继续展示已保存值；同学校、同账号可继续复用。小眼睛只显示当前输入，不从磁盘解密显示历史密码。换账号 / 学校或换 Windows 用户时需要重新输入。

### 运营商为什么可能有“校园网”？

某些学校的认证服务有本校出口和运营商出口，“校园网”是服务选项。需要选择本人已开通的服务；不能根据账号猜，也不意味着所有服务都能访问外网。普通湘大配置无需显示这一行。

### 如何知道到底用没用密码登录？

查看运行记录中的“是否提交认证”。`ALREADY_ONLINE` 表示检测时已能上网，可能是无感或原有会话；`ONLINE_AFTER_AUTH` 且已提交表示完成了本轮密码认证并确认外网。运行记录缺失时不能推断已经成功。

### 换一所学校，填网址和 Wi-Fi 名称就行吗？

不行。还需校区入口、来源白名单、页面 / 协议特征、运营商映射、成功判定和现场验收。参考 [适配指南](ADAPTERS.md)。
