# 数据与隐私

## 本机保存

设置包含学校、Wi-Fi 名称、账号和时间。密码单独使用 Windows DPAPI `CurrentUser` 加密，按学校和账号绑定。默认数据目录见 [使用指南](USAGE.md#版本与数据)。同一 Windows 会话中的程序和恶意软件仍可能取得运行时密码，DPAPI 不替代系统安全。

根目录 `data-location.json` 包含当前用户 SID 与实际本地路径；运行日志、诊断、凭据和浏览器状态均不适合公开。它们在 `.gitignore` 中排除，但用户手动上传文件仍需要自己核对。

## 联网行为

- 将认证所需账号和密码发给已配置学校的受信认证来源。
- 检查外网时访问公共连通性探测地址，当前代码可见 `engine/connectivity.mjs` 和各校 `discoveryProbes`。
- 使用本机 Edge 的独立后台上下文，不读用户的浏览器历史或保存的密码。
- 图片验证码识别使用本地模型；不接入第三方打码服务。
- 源码安装时 npm 下载依赖，发布包包含对应依赖。项目没有自己的遥测或账户后台。

部分学校门户使用 HTTP。本地密码加密和应用层参数编码不等同于传输加密，不能改变学校链路的性质。

## 运行记录与反馈

运行记录有数量和大小上限。反馈导出重新构造白名单字段，保留时间、耗时、结果码、是否提交认证、公开学校 ID 和任务状态等。导出不包含账号、密码、SSID、IP、MAC、文件路径、Cookie、完整认证地址或内部计划令牌。

原始日志与公开反馈文件不是同一回事。请优先使用窗口内“运行记录 → 导出反馈”，上传前再检查；截图也应裁去账号、Wi-Fi 名称及个人内容。
